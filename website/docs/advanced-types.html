Advanced Types

Tezz natively supports Rust-like Enums and Traits which compile directly into zero-overhead JS equivalents.

enum Status {
  PENDING,
  ACTIVE,
  DELETED
}
// Compiles to Object.freeze({ ... })

Traits

Define interfaces for compile-time structure verification.

trait UserProvider {
  fn getUser(id)
  fn saveUser(user)
}
