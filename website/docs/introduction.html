Introduction

Tezz (तेज़) is a modern, blazing fast backend programming language that gives you the strict, clean, and elegant syntax of languages like Rust or Go, while compiling directly into highly optimized JavaScript.

What exactly is Tezz?

Building a robust API shouldn't require hundreds of lines of boilerplate, 15 different npm packages, and a maze of configuration files. Tezz was built from the ground up to solve the backend fatigue developers face today.

Instead of creating a heavy, isolated runtime engine, Tezz is a transpiled language. When you write a .tezz file, our lightning-fast compiler parses it and outputs pure, boilerplate-free JavaScript. This allows Tezz to run seamlessly on Node.js, Cloudflare Workers, or anywhere else V8 runs, directly piggybacking on billions of dollars of JS engine optimizations.

Why Tezz? The DX Philosophy

The core philosophy of Tezz is unmatched Developer Experience (DX). We believe you should spend your time writing business logic, not wrangling HTTP headers.

  • Zero Configuration: Out of the box, Tezz handles CORS preflights, JSON parsing, asynchronous unwrapping, and HTTP status code mappings. No Express or middleware setup required.
  • Edge-Ready: Tezz compiles to zero-overhead JS that is perfectly tailored for Edge networks like Cloudflare Workers.
  • NPM Compatibility: Because it compiles to JavaScript, you can natively import and use any package from the vast npm ecosystem.
  • Familiar but Better: Enjoy a C-style syntax with strong typing, simplified error handling, and robust concurrency tools, without the bloated configuration of TypeScript.
