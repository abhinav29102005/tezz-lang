Standard Libraries

To avoid "double code" and standardize development, Tezz publishes official packages to the NPM registry that can be imported directly into your .tezz files.

tezz-database

A native database client for Tezz, officially supporting Turso LibSQL over HTTP. Ideal for Edge/Worker environments.

npm install tezz-database
import createClient from "tezz-database"

let db = createClient({ url: "YOUR_TURSO_URL", token: "YOUR_TOKEN" })
let result = await db.execute("SELECT * FROM users")
print(result.rows)

tezz-jwt

Native JSON Web Token support for signing and verifying tokens.

npm install tezz-jwt
import { sign, verify } from "tezz-jwt"

let token = sign({ user: "abhinav" }, "secret-key")
