Standard Libraries

Tezz comes with a rich set of 0-overhead standard libraries built to give you the best features from all other languages.

tezz-channels (Go-style Concurrency)

npm install tezz-channels
import tezz_channels from "tezz-channels"
rakho ch = tezz_channels.createChannel()
async fn run() {
  await ch.push("Message")
}
rakho msg = await ch.pop()

tezz-result (Rust-style Safety)

npm install tezz-result
import tezz_result from "tezz-result"
rakho ok = tezz_result.Result.Ok("Success!")
console.log(ok.unwrap())

tezz-actor (Elixir-style Actors)

npm install tezz-actor
import tezz_actor from "tezz-actor"
rakho actor = tezz_actor.spawnActor((msg) => { console.log(msg) })
actor.send("Hello")

tezz-linq (C#-style Queries)

npm install tezz-linq
import tezz_linq from "tezz-linq"
rakho res = tezz_linq.From([1,5,2]).Where((x) => x > 2).ToList()

tezz-tensor (NumPy/PyTorch-style Math)

npm install tezz-tensor
import tezz_tensor from "tezz-tensor"
rakho t1 = tezz_tensor.createTensor([1, 2, 3])

tezz-frame (Pandas-style DataFrames)

npm install tezz-frame
import tezz_frame from "tezz-frame"
rakho df = tezz_frame.createDataFrame([{id: 1, name: "Alice"}])

tezz-brain (Embedded ML)

npm install tezz-brain
import tezz_brain from "tezz-brain"
rakho model = tezz_brain.createSimpleLinearRegression()
model.fit(X, y)

tezz-vision (High-performance Image Processing)

npm install tezz-vision
import tezz_vision from "tezz-vision"
rakho processor = tezz_vision.createImageProcessor()
