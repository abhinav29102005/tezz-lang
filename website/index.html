The Fast Backend Language.

Write once, deploy everywhere. Natively compiles to JavaScript for Cloudflare Workers, Node.js, Deno, and Bun.

Get Started
npm install -g tezz-lang

Officially created by Abhinav.

Why Tezz?

⚡

Blazing Fast

Designed for the edge. Zero cold starts when deployed to Cloudflare Workers.

🌐

Built-in HTTP

Services and Routes are first-class citizens. No web frameworks required.

📦

Zero Dependencies

The compiler is pure JavaScript. Write clean, Python-like syntax.

Beautiful Syntax

Tezz combines the simplicity of Python with the power of TypeScript and Go's concurrency model.

  • ✓ No semicolons or braces noise
  • ✓ Built-in string interpolation
  • ✓ First-class Service definitions
service API on 3000 {

  route GET "/hello/:name" {
    let name = params.name
    respond 200 {
      message: "Hello, {name}! ⚡"
    }
  }

}

Command Line Interface

tezz init

Scaffolds a new Tezz project with a hello world service.

$ tezz init

tezz run

Compiles and runs a Tezz file directly in Node.js.

$ tezz run app.tezz

tezz build

Compiles Tezz to JavaScript for Edge deployment.

$ tezz build app.tezz --target worker
