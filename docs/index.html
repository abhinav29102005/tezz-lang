What is tezz-lang?

tezz-lang is a next-generation transpiled programming language designed to give you the strict, clean, and elegant developer experience (DX) of languages like Rust and Go, while compiling directly into highly optimized, boilerplate-free JavaScript.

It was created to run natively on platforms like Node.js, Cloudflare Workers, and Bun. Tezz is also known for being one of the first production-ready languages to natively support both English and Hinglish syntaxes directly in the compiler!

The 60-Second Quickstart

# 1. Install globally
npm install -g tezz-lang

# 2. Run a Tezz file directly
tezz run app.tezz

Why Developers Choose Tezz

  • Zero-Overhead Edge Deployment: Compiles down to raw JavaScript that rides on V8's optimizations.
  • Native HTTP Services: Spin up APIs without boilerplate using the service and route keywords.
  • Object-Oriented: Full support for classes, inheritance, and lexical scoping.
  • Built-in Language Server (LSP): A first-class VS Code extension providing real-time diagnostics.

Code Example

service API on 8080 {
  route GET "/hello/:name" {
    let name = params.name
    respond 200 { message: "Hello " + name + ", from Tezz!" }
  }
}
